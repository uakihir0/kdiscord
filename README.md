# kdiscord

kdiscord is a Discord client library created using Kotlin Multiplatform.

> [!WARNING]
> kdiscord authenticates using a **user token** (self-bot style). Automating a user account
> violates [Discord's Terms of Service](https://discord.com/terms) and may result in account
> termination. Use this library at your own risk.
